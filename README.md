# alts-compose
Окружение для Docker Compose.


## #1 Запуск
1. Установить [Docker](https://docs.docker.com/get-started/) с [Docker Compose](https://docs.docker.com/compose/).
2. Склонировать репозиторий.
3. Для запуска, в папке с файлом `docker-compose.yaml` необходимо выполнить команду:
   
   ```sh
   docker compose up -d
   ```


## #2 Остановка
Для остановки, в той же папке необходимо выполнить команду:
   
```sh
docker compose down
```


## #3 Очистка
Для того, чтобы **полностью очистить** данные системы, необходимо:
1. Остановить и дождаться остановки всех сервисов.
2. Удалить папку `data`.
